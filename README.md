# 서재

책을 쓰고, 세계를 짓고, 어디서든 이어 읽는 곳. 친구와 서로의 책을 읽고 주석 · 평가를 남긴다. (한국어, 폰 · 태블릿 · PC)

- **서재**(`#/library`): 이어 읽기, 내가 쓴 책 · 친구의 책 · 들인 책, 휴지통
  - **기기에 받아 두기**: 서재를 열면 내 책과 친구가 공유한 최신 판을 기기에 자동으로 받아 둔다(「기기에 있음」). 인터넷이 없으면 받아 둔 책으로 서재가 열린다
  - **리더**: 글을 골라 밑줄 · 메모, 소리 내어 읽기(지금 자리부터 그 장 끝까지), 전자책(EPUB)으로 받기, 넓은 화면 두 쪽 펼침 / 좁은 화면 한 쪽, 또는 세로 스크롤. 글자 크기 · 줄 간격 · 명조/고딕 · 바탕(흰 종이 · 미색 · 어두움), 목차, 책갈피, 책 안 찾기. 읽던 자리는 (장, 장 안 위치)로 저장해 기기를 바꿔도 같은 곳이 열린다. 한 번 연 책은 인터넷 없이도 읽힌다
  - **파일로 들이기**: EPUB · TXT(UTF-8 · EUC-KR) · Markdown · HTML · Word(.docx) · PDF(글자가 든 것). 파일은 기기 안에서 읽고 글만 저장. 제목 기호 · 「제1장」 같은 줄로 장을 나눠 미리 본 뒤 넣는다. 들인 책은 나만 보이고 공유할 수 없다
  - **자유 이용 책 찾기**(`#/discover`): 한국어 위키문헌(ko.wikisource.org, 하위 문서를 장으로) · 구텐베르크 프로젝트(Gutendex 목록, 파일은 gutenberg.org 에서만)
- **밑줄 모음**(`#/lines`): 리더에서 글을 골라 그은 밑줄 · 메모를 책별로, 마크다운으로 받기
- **빠른 이동**: Ctrl/⌘ + K (편집기 안에서는 Ctrl/⌘ + Shift + K) → 책 · 장 · 세계 · 세계관 항목 이름으로 바로 가기
- **찾기**(`#/search`): 모든 책(내 원고 · 들인 책 · 친구가 공유한 최신 판)의 제목 · 본문에서 찾고, 누르면 그 장의 그 말로
- **집필실**(`#/studio`): 오늘 · 7일 · 연속 쓴 날, 쓴 날 달력, 새 책 틀(빈 책 · 단편 · 기승전결 · 3막 구조 · 영웅의 여정 12단계 · 산문집)
  - **작업 화면**(`#/write/책`): 원고 목록(부 → 장 → 장면, 끌어 옮기기 · 폰은 메뉴로 위/아래, 복제, 휴지통 · 되살리기, 원고에 안 들어가는 「메모」)
  - **편집기**: 마크다운을 글 모양 그대로, 굵게 · 기울임 · 장면 나눔 · 인용, `[[세계관 항목]]` 자동 완성 · 마우스를 올리면 요약 · 없는 이름은 빨간 점선(Ctrl/⌘+클릭으로 만들기), `%%작가 메모%%`(리더 · 공유본에서 빠짐), 찾기 · 바꾸기, 집중 모드, 타자기 모드, 대사 색, 글자 크기 · 원고 폭, 15/25/45분 집중 쓰기
  - 글자 수(공백 제외 · 포함), 원고지 매수 어림(공백 포함 ÷ 200), 고른 글 글자 수, 이번에 쓴 글자
  - **곁 패널**: 장 정보(줄거리 · 상태 · 색 · 시점 인물 · 장소 · 이야기 속 시간 · 꼬리표 · 장 메모) / 세계관(이 장에 나오는 항목, 항목 보기, 본문에 넣기) / 기록(10분마다 자동 · 직접, 지금 글과 나란히 비교, 되돌리기) / 퇴고(가까운 반복 · 긴 문장 · 자주 쓴 말 · 끝맺음 · 같은 말로 시작한 문장 · 대사 비율, 편집기에 표시) / 친구 주석(장 · 책 전체, 원고의 그 문장으로, 반영함)
  - 원고 목록 거르기(제목 · 시점 · 상태 · #꼬리표), 칸마다 목표 글자, 커서에서 「여기서 나누기」 · 「아래 칸과 합치기」(전 글은 기록에), 소리 내어 듣기(기기의 읽어 주기 목소리, 커서부터)
  - **플롯 선**: 이야기 줄기(본 줄거리 · 곁가지 · 인물별) × 장 표, 빈칸으로 잊은 줄기 찾기
  - **찾아 바꾸기**: 책 전체에서 찾아 장별로 미리 보고 골라 바꾸기(정규식 가능), 바꾸기 전 글은 장마다 기록에
  - 곁 패널 「세계관」에 이 장과 이어진 연표 사건
  - 코르크보드(카드 끌어 순서, 시점 인물로 거르기) · 개요(표로 바로 고치기) · 통계(목표 분량 · 마감일 → 하루 몫, 하루 목표, 장별 분량) · 작가 노트 · 책 설정(표지 색 · 세계관 연결 · 공유 · 내보내기 .md/.txt/인쇄용 .html/전자책 EPUB, 공유한 판과 지금 원고 비교)
- **세계관**(`#/worlds`): 항목 여러 개 한꺼번에 넣기(줄마다 「이름 - 요약」), 지도(그림을 올려 핀 꽂기 · 항목과 잇기 · 확대 · 핀 끌어 옮기기), 항목 그림(초상), 인물 질문지, 관계 종류(가족 · 연인 · 친구 · 적 · 소속 · 기타, 관계도 색 · 거르기), 연표 사건을 원고의 장과 잇기, 원고에 [[링크]]로 썼지만 없는 이름 모아 항목으로 만들기, 항목 이름을 바꾸면 원고 속 이름도 한 번에 바꾸기, 항목(인물 · 장소 · 세력 · 사물 · 사건 · 개념/규칙 · 종족 · 기타, 종류마다 칸 서식, 다른 이름, 꼬리표, 색, 본문 속 `[[링크]]`), 관계(관계도: 끌어 옮기기 · 종류 거르기), 연표(여러 줄 · 같은 순서는 같은 칸), 등장 분포(항목 × 장), 원고에 나오는 곳, 설정집 내보내기
- **열람실**(`#/hall`): 공유된 책 · 새 소식(메뉴에 안 본 소식 수). 공유하면 원고를 「판」으로 찍어 보여 주고(계속 고쳐도 친구가 읽는 글은 그대로), 친구는 글을 골라 주석 · 답글, 장마다 좋아요, 책에 별점 · 한 줄 평. 판이 바뀌어도 같은 문장을 찾아 주석이 따라온다
- **계정**(`#/account`): 아이디 · 비밀번호(이메일 없음), 가입은 초대 코드, 화면 밝기, 닉네임 · 비밀번호 바꾸기, 전부 내려받기(.json) · 백업에서 되살리기(새 사본으로, 그림 제외), 모든 기기 로그아웃, 계정 지우기

## 실행

```bash
npm install
npm test           # 들이기 · 퇴고 · 주석 자리 · 보안 시험
npm run build      # 배포용 빌드 (dist)
echo 'INVITE_CODE=아무거나' > .dev.vars
npx wrangler dev   # 빌드한 사이트 + 서버를 이 컴퓨터에서 (http://localhost:8787)
```

## 배포 (Cloudflare Workers, 무료 플랜 가능)

`wrangler.jsonc` 그대로 씁니다 (워커 이름 `book`). Cloudflare 대시보드에서 이 GitHub 저장소를 `book` 워커에 연결해 두면 푸시할 때마다 자동으로 배포됩니다 (빌드 명령 `npm run build`, 배포 명령 `npx wrangler deploy`). 서버(Durable Object + SQLite)도 함께 올라갑니다.

**초대 코드**: 대시보드 → Workers & Pages → book → Settings → Variables and Secrets → Add → 종류 **Secret**, 이름 `INVITE_CODE`, 값에 친구에게 알려 줄 코드. 이 값이 없으면 가입이 닫혀 있습니다 (저장소가 공개라 코드에 넣지 않습니다).

## 구조

- `worker/` — `index.ts`(/api 를 서버로), `library.ts`(Durable Object: 계정 · 책 · 장 · 기록 · 세계관 · 판 · 주석 · 평가 · 읽던 자리), `external.ts`(구텐베르크 · 위키문헌), `security.ts`, `util.ts`
- `src/lib/` — 서버 부르기, 기기 저장(IndexedDB: 책 사본 · 못 보낸 원고), 들이기(`importers.ts`, `split.ts`, `htmlToMd.ts`), 쪽 나누기(`paginate.ts`), 주석 자리(`anchor.ts`), 퇴고(`analyze.ts`), 내보내기
- `src/features/` — library(서재 · 리더 · 들이기 · 찾기) · studio(집필실) · world(세계관) · community(열람실) · account · auth
- `public/seed/` — 아티팩트 「작은 서재」에 있던 「새벽을 건너는 꿈」과 「작품 분석」 (처음 로그인하면 가져오기)

새 판이 배포되면 열려 있는 화면에 「새 버전이 나왔어요 · 새로고침」 안내가 뜬다.

## 저장과 충돌

- 원고는 멈추고 1초 뒤 기기에 먼저, 곧 서버로. 인터넷이 없으면 기기에 두었다가 연결되면 보낸다.
- 다른 기기에서 먼저 고친 장을 덮어쓸 때는 서버의 그 글을 「기록」에 남긴다 → 글이 사라지지 않는다.
- 지우기는 휴지통(책 30일). 장은 바인더 아래 휴지통에서 되살린다.
