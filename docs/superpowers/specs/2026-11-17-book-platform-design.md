# 서재 (book) 설계

작성일 2026-11-17 · 주소 `book.silent-recipe-8e5c.workers.dev`

## 1. 왜 만드는가

- **주된 목적**: 내가 책을 쓰고 고치는 작업실. 그리고 내가 쓴 책을 폰·태블릿·PC 어디서든 편하게 읽는 것.
- **곁들임**: 친구 한두 명이 같이 쓰면서 서로 쓴 책을 읽고, 주석을 달고, 평가한다.
- 출발점은 claude.ai 아티팩트 「작은 서재」(책장 + 두 쪽 펼침 리더 + .md 들이기). 그 리더의 장점(두 쪽 펼침, 쪽 나누기, 목차, 글자 크기, 읽던 자리)은 살리고 나머지는 새로 만든다.

## 2. 목표 · 하지 않을 것 · 실패로 볼 것

**목표**
- 시중 집필 도구(Scrivener류의 장 관리·스냅숏, 세계관 위키류의 항목·관계·연표)에서 쓸모 있는 것을 한 곳에, 한국어 글쓰기에 맞게.
- 세계관을 핵심 기능으로: 원고와 세계관이 서로 이어진다(원고 속 이름 ↔ 세계관 항목).
- 어느 기기에서든 같은 책, 같은 읽던 자리. 인터넷이 끊겨도 내 책은 읽히고, 쓰던 글은 사라지지 않는다.
- UI: 「깔끔한 도서관」. 아티팩트의 나무 책장 그림과 다르게, 정돈된 열람실 느낌(아래 7장).

**하지 않을 것 (이번 범위 밖)**
- 아무나 가입하는 공개 서비스, 신고·관리자 기능, 검색 노출.
- 지도 그림 위에 핀 꽂기(사진 저장소가 필요해서 나중에), AI 글쓰기 도우미, 여러 사람이 한 원고를 동시에 편집.
- EPUB·PDF 내보내기 (나중 후보. 이번에는 .md · .txt · .html).

**실패로 볼 것 (기능이 돌아가도)**
- 쓰던 글이 한 번이라도 사라짐 (저장 충돌·오프라인·실수로 지움 포함).
- 폰에서 읽기가 불편함 (글자가 작거나, 쪽 넘김이 끊기거나, 읽던 자리를 잃음).
- 화면이 복잡해서 「쓰기」보다 「메뉴 찾기」에 시간이 듦.

## 3. 제약

- Cloudflare Workers 무료 플랜 기준. life 앱과 같은 구조(사용자 선택): Vite + React + TypeScript, `/api/*` 만 Worker → Durable Object 하나(SQLite).
- Durable Object SQLite 한 칸 최대 2MB (life 설계 문서에 적힌 Cloudflare 공식 제한). → 장 하나 본문은 한 칸에 넣되, 1.5MB 넘으면 저장을 막고 장을 나누라고 안내.
- 자동 배포: Cloudflare 대시보드에서 이 저장소를 `book` 워커에 연결(사용자가 이미 해 둠). 빌드 `npm run build`, 배포 `npx wrangler deploy`. `wrangler.jsonc` 의 `name` 은 반드시 `book`.
- 이 작업 환경에서는 workers.dev 와 Cloudflare 문서에 접속이 막혀 있어, 실제 배포 화면은 사용자가 확인한다. 개발 중 확인은 `wrangler dev`(로컬)로 한다.

## 4. 만드는 방식 (Approaches)

| | 방식 | 장단점 | 결정 |
|---|---|---|---|
| A | life 와 같은 구조: React + TS, Worker + Durable Object(SQLite), PWA | 사용자가 이미 운영 중이라 배포·설정이 익숙. 큰 화면(편집기·세계관·커뮤니티)을 나눠 키우기 좋음 | **사용자 선택** |
| B | 아티팩트처럼 HTML 한 장 + 서버 | 빌드 없음. 기능이 커지면 관리가 급격히 어려움 | 버림 |

데이터베이스는 D1 대신 Durable Object SQLite: life 와 같은 방식이라 코드(로그인·보안)를 그대로 옮겨 쓸 수 있고, 따로 데이터베이스를 만들 필요가 없다. (내 판단)

## 5. 화면 구성

메뉴(PC 왼쪽 세로, 폰 아래 탭) — life 지침과 같이 세부 탭도 왼쪽(폰은 아래) 세부 메뉴에 둔다.

1. **서재** — 내 책 + 친구가 공유한 책, 이어 읽기
2. **집필실** — 책 쓰기·고치기
3. **세계관** — 세계 만들기
4. **열람실** — 커뮤니티(공유된 책, 주석, 평가)
5. **계정** — 로그인·설정

### 5.1 서재 · 리더

- 목록: 카드 목록(표지 색 띠 + 제목 + 부제 + 진행률). 「읽는 중」「내 책」「친구의 책」 칸.
- 리더(아티팩트의 쪽 나누기를 TypeScript 로 옮김):
  - 넓은 화면 두 쪽 펼침, 좁은 화면 한 쪽. 화면 누르기 · 밀기 · 방향키 · 스크롤바 막대로 넘김.
  - 목차, 글자 크기, **줄 간격, 글꼴(명조/고딕), 바탕(흰 종이 · 미색 · 어두움)**, 넘김 방식(쪽 넘김 / 세로 스크롤) — 기기마다 따로 기억.
  - 읽던 자리: 장 + 장 안의 위치(글자 위치)로 저장 → 기기마다 화면 크기가 달라도 같은 곳이 열림. 계정에 동기화.
  - 책갈피(여러 개, 한 줄 메모), 책 안 찾기.
  - 원고를 고치는 중이어도, 리더는 그 책의 최신 저장본을 보여 준다.
- 오프라인: 한 번 연 책은 기기(IndexedDB)에 보관 → 인터넷 없이 읽기. 앱 설치(PWA) 가능.
- 기본 책 가져오기: 처음 로그인하면 「새벽을 건너는 꿈」을 내 책으로 가져올 수 있다(`#` = 부, `##` = 장으로 나눔). 「작품 분석」은 그 책의 **작가 노트**로 들어간다. (세계관 항목으로 자동 변환하지 않는다: 내용을 지어내지 않기 위해. 사용자가 직접 옮긴다.)

### 5.2 집필실

한 책을 열면 세 칸: **왼쪽 원고 목록 · 가운데 편집기 · 오른쪽 곁 패널** (폰: 한 칸씩, 아래 세부 메뉴로 전환).

- **원고 목록(바인더)**: 부 → 장 → 장면 세 단계 나무. 끌어서 순서·위치 바꾸기, 이름 바꾸기, 복제, 휴지통(30일 보관 뒤 삭제, 되살리기 가능).
- **편집기**: CodeMirror 6 기반 마크다운 편집기 (원고는 마크다운으로 저장 → 리더·내보내기와 같은 형식).
  - 쓰면서 바로 보이는 서식(제목·강조·인용·장면 나눔 `***`)을 글 모양 그대로 보여 줌. 서식 단추(굵게·기울임·인용·장면 나눔)도.
  - 집중 모드(메뉴 숨김, 지금 문단만 진하게), 타자기 모드(쓰는 줄이 화면 가운데).
  - 찾기 · 바꾸기 (이 장 / 책 전체, 대소문자·정규식 선택).
  - 자동 저장: 멈추고 1초 뒤 기기에 먼저 저장, 서버에도 곧바로. 화면에 「저장됨 / 기기에만 저장됨 / 저장 중」 표시.
- **곁 패널** (탭):
  - 장 정보: 줄거리 요약(시놉시스), 상태(구상 · 초안 · 수정 중 · 완성), 색 표시, 장 메모.
  - 세계관: 이 책에 연결된 세계의 항목 찾기·보기. **이 장에 나오는 항목**(이름·다른 이름이 본문에 나오면 자동으로 모음).
  - 기록(스냅숏): 직접 찍기(이름 붙이기) + 자동(저장 사이 10분 이상 지나면 하나). 고른 기록과 지금 글을 나란히 비교(바뀐 곳 표시), 되돌리기(되돌리기 전 상태도 기록으로 남김). 장마다 최근 100개.
  - 작가 노트: 책 전체 메모(마크다운).
- **원고 속 세계관 링크**: `[[이름]]` 을 쓰면 세계관 항목으로 연결. `[[` 를 치면 항목 이름 자동 완성. 링크에 마우스를 올리면(폰: 누르면) 항목 요약 카드. 리더에서는 링크 표시 없이 평범한 글로 보인다(설정으로 켜기 가능).
- **코르크보드**: 장·장면을 카드(제목 + 요약 + 상태 색)로 펼쳐 보고 끌어서 순서 바꾸기.
- **통계 · 목표**: 글자 수(공백 포함/제외), 원고지 매수(공백 포함 글자 수 ÷ 200 으로 어림, 화면에 「어림」 표시), 오늘 쓴 글자, 하루 목표와 연속 일수, 책 전체 목표 분량과 마감일 → 하루에 써야 할 양.
- **들이기 · 내보내기**: .md/.txt 들이기(제목 기호로 부·장 자동 나눔, 미리 보고 확정). 내보내기 .md · .txt · .html(인쇄용 서식 포함).
- **표지**: 표지 색(팔레트) + 제목·부제·저자명. (사진 표지는 범위 밖)

### 5.3 세계관

세계는 책과 따로 만들고, 책 하나에 세계 하나를 연결한다(여러 책이 한 세계를 함께 써도 됨).

- **항목**: 종류 — 인물 · 장소 · 세력 · 사물 · 사건 · 개념/규칙 · 종족 · 기타. 종류마다 기본 칸(예: 인물 = 나이, 외모, 성격, 바라는 것, 두려운 것, 비밀). 칸은 더하고 빼고 이름 바꾸기 가능(세계마다 종류별 서식 저장).
  - 공통: 이름, 다른 이름(별명 — 원고 속 등장 찾기에 씀), 한 줄 요약, 본문(마크다운, `[[다른 항목]]` 링크), 꼬리표, 대표 색.
  - 항목 페이지 아래: **나오는 곳**(어느 책 어느 장에 이름이 나오는지, 누르면 그 장으로), 이 항목을 링크한 항목들.
- **관계**: 두 항목 사이에 관계(예: 홍설 —엄마— 엄마). 관계도(그래프 그림, 끌어 옮기기, 종류별 거르기). 항목 페이지에도 관계 목록.
- **연표**: 사건마다 「세계 안 날짜 표기」(자유 글, 예 「현실 2년 차 봄」)와 「정렬 순서」(숫자). 여러 줄(예: 꿈의 시간 / 현실의 시간)로 나란히. 사건에 관련 항목·장 연결.
- **찾기**: 세계 안 전체 찾기, 종류·꼬리표 거르기.
- **내보내기**: 세계관 설정집(.md · .html).

### 5.4 열람실 (커뮤니티)

- **공유**: 책마다 「친구에게 공유」를 누르면 그 순간 원고를 **판(版)** 으로 찍어 공개한다(예: 「1판 · 11월 17일」). 계속 고쳐도 친구는 찍어 둔 판을 읽는다. 새 판을 찍으면 친구 화면에 「새 판」 표시. 공유 끄기 가능.
  - 공개 범위: 이 사이트에 가입한 사람 전부(= 초대받은 친구들). 세계관도 「함께 공유」를 고르면 읽기 전용으로 보임.
- **주석**: 공유된 책을 리더(세로 스크롤 모드)로 읽다가 글을 골라 주석 달기. 고른 글에 형광 표시, 옆 여백(폰: 아래 서랍)에 주석. 답글, 「반영함」 표시(작가만). 주석은 판에 붙어서, 새 판을 찍어도 같은 문장이 있으면 따라온다(문장을 못 찾으면 「옛 판의 주석」으로 따로 모음).
- **평가**: 책마다 사람당 별점 1~5 + 한 줄 평(고치기 가능). 장마다 「좋아요」.
- **작가 화면**: 내 책에 달린 주석을 장별로 모아 보기 → 누르면 집필실의 그 장, 그 문장으로.
- **소식**: 열람실 첫 화면에 새로 공유된 판, 내 책에 새로 달린 주석·평가.

### 5.5 계정

- life 와 같은 방식: 아이디 + 비밀번호(이메일 없음), 닉네임.
- **가입은 초대 코드가 있어야 가능** (주소가 공개라 모르는 사람이 가입하는 것을 막음). 초대 코드는 Cloudflare 비밀값 `INVITE_CODE` 로 사용자가 정한다. (내 판단 — 확인 필요)
- 비밀번호·닉네임 바꾸기, 모든 기기에서 로그아웃, 내 자료 전부 내려받기(.json 백업), 계정 지우기.
- 로그인하지 않으면: 공유된 책 없이, 기기에만 저장되는 「손님 서재」(아티팩트처럼). 로그인하면 계정으로 옮길지 묻는다.

## 6. 데이터 · 동기화

**서버 (Durable Object 하나, SQLite)**

- `users`, `sessions` — life 그대로 (PBKDF2-SHA256 10만 번 + 소금, 토큰은 SHA-256 만 저장, HttpOnly·Secure·SameSite=Strict 쿠키, Origin·JSON 확인, IP별 시도 제한).
- `books` (id, owner, title, subtitle, author, color, world_id, goal_chars, deadline, notes, created, updated, deleted)
- `nodes` (id, book_id, parent_id, kind: part|chapter|scene, sort, title, body, synopsis, status, label, words, updated, rev, deleted)
- `snapshots` (id, node_id, body, label, auto, at)
- `worlds`, `templates`(세계·종류별 칸), `entries`, `relations`, `timeline_tracks`, `events`
- `editions` (id, book_id, number, title, created, content: 판 전체 JSON — 2MB 넘으면 장별 행으로 나눔), `annotations` (id, edition_id, node_id, quote, prefix, suffix, pos, body, author, parent_id, resolved, created), `ratings`, `likes`
- `progress` (user, book/edition, node_id, offset, at), `bookmarks`, `daily_words` (user, day, chars)

**동기화 규칙**
- 기기에는 IndexedDB 로 내 자료 사본. 화면은 기기 사본을 먼저 보여 주고 서버에서 새로 받는다.
- 저장은 「장(노드) 단위」 + `rev`(고칠 때마다 1 증가). 서버의 rev 가 내가 받은 것보다 크면(다른 기기에서 먼저 고침) **덮어쓰지 않고**: 서버 쪽 글을 자동 스냅숏으로 남긴 뒤 내 글을 저장하고, 화면에 「다른 기기에서 고친 글을 기록에 남겼어요」 알림. → 어떤 경우에도 글이 사라지지 않음.
- 오프라인에서 고친 것은 대기열에 두었다가 연결되면 순서대로 보낸다.
- 지우기는 실제 삭제 대신 `deleted` 표시(휴지통 30일).

## 7. UI — 깔끔한 도서관

- 느낌: 밝은 열람실. 따뜻한 흰 종이색 바탕, 얇은 선, 넉넉한 여백. 책장 그림·나뭇결 없음. 색은 아껴 쓴다(life 지침 「이모지·굵은 테두리·색을 아껴 쓴다」를 따름).
- 글꼴: 제목·본문 읽기 = 명조(Noto Serif KR), 화면 글자 = Pretendard. 둘 다 사이트에 함께 올려 오프라인에서도 같은 글꼴. (사용할 글꼴 묶음이 npm 에 있는지는 만들 때 확인)
- 색: 종이 `#faf8f3`, 글 `#1f1d1a`, 흐린 글 `#77736b`, 선 `#e6e2d9`, 강조 짙은 초록 `#2f5d50`(아티팩트의 강조색을 이어받음). 어두운 화면도 같은 짜임으로.
- 책 카드: 도서관 대출 카드처럼 — 왼쪽 얇은 표지 색 띠, 제목(명조), 아래 작은 글씨로 분량·상태·진행률.
- 움직임은 짧고 조용하게(쪽 넘김 페이드, 패널 미끄러짐). 「움직임 줄이기」 설정을 따른다.

## 8. 만드는 순서 (단계마다 배포해서 써 볼 수 있게)

1. 뼈대: 프로젝트, 배포 설정, 로그인·가입(초대 코드), 화면 틀(메뉴·도서관 UI), 오프라인 앱
2. 서재 · 리더 + 기본 책 가져오기
3. 집필실 (바인더·편집기·자동 저장·스냅숏·통계·들이기/내보내기·코르크보드)
4. 세계관 (항목·서식·관계도·연표·원고 연결)
5. 열람실 (판 공유·주석·평가·소식)
6. 다듬기: 손님 서재 옮기기, 백업, 접근성·폰 화면 점검

## 9. 확인 방법

- 서버: vitest 로 보안(쿠키·비밀번호 규칙·초대 코드)과 동기화 규칙(rev 충돌 시 스냅숏) 시험.
- 화면 규칙: 쪽 나누기·들이기(제목으로 나누기)·글자 수·원고지 어림·주석 문장 찾기 시험.
- `wrangler dev` 로 로컬 실행 + Playwright 로 PC·폰 크기 화면 확인.

## 10. 내가 정한 것 (사용자 확인용)

- 데이터베이스: D1 대신 Durable Object SQLite (life 와 같게).
- 가입에 초대 코드 필요.
- 편집기 저장 형식: 마크다운.
- 공유는 「판」으로 찍어서 (계속 고쳐도 친구가 읽는 글은 그대로).
- 공개 범위: 사이트 가입자 전원.
- 「작품 분석」은 세계관이 아니라 작가 노트로 가져옴.
- 범위 밖: 지도 핀, AI, 동시 편집, EPUB/PDF.

## 11. 추가 요청 (2026-11-17, 승인 뒤)

사용자: 「실제 존재하는 책도 파일을 얻어 넣을 수 있게, 파일 있는 책을 찾을 수 있게, 책 쓰기 기능을 더 발전시켜 달라. 알아서 만들고 더 묻지 말 것.」

- **파일로 들이기**: EPUB · TXT(UTF-8/EUC-KR) · MD · HTML · DOCX · PDF(글자) → 장으로 나눠 미리 보고 넣기. 들인 책은 나만 보고 공유 불가(저작권).
- **자유 이용 책 찾기**: 한국어 위키문헌 · 구텐베르크(Gutendex). 서버는 정해진 주소만 부른다. (이 작업 환경에서는 두 곳 모두 접속이 막혀 실제 응답으로 시험하지 못함 — 공개된 API 형식대로 만들고 응답 모양을 방어적으로 읽음)
- **찾기**: 모든 책 제목 · 본문 찾기 → 리더/집필실의 그 자리로.
- **집필 더하기**: 책 틀(기승전결 · 3막 · 영웅의 여정 · 산문집), 개요 표, 퇴고 도우미(어림), 집중 쓰기 타이머, 장면 정보(시점 · 장소 · 시간 · 꼬리표), 등장 분포, `%%작가 메모%%`.
- 손님 서재(로그인 없이 기기에만)는 빼고, 로그인 뒤 오프라인 읽기 · 쓰기로 대신함 (내 판단).
